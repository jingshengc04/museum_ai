# Ready-made material for single shots

Anything here is used instead of generating it. Shot numbers are two digits and match the storyboard.

| File | Replaces |
| --- | --- |
| `shot_03.mp4` | the video clip for shot 3 (for example one made in the fal playground or web agent) |
| `shot_03.mp3` | the narration for shot 3 |
| `shot_03.words.json` | word timings for that narration: `[{"w": "Then,", "t0": 0.1, "t1": 0.4}, ...]` (optional, estimated if missing) |
| `ambient.mp3` | the sound bed under the whole film (looped) |

A clip of any size or length works: it is cropped to the film's frame and trimmed, slowed or frozen to fit its narration.
